# Incompressible N-S solver

- 2D
- Structured grid
- Finite-difference method
- Pressure projection method
- 3rd order Runge-Kutta time integration

## Environment

Install the following:

```
pip install poetry
poetry shell
poetry install
```

## Example run

From project root:

```
cd src/
python3 runSolver.py
```
